# 📦 Inventory Management System

A Python-based command-line application designed to simplify inventory management through an intuitive and organized interface. This project enables users to efficiently manage product records by performing essential operations such as adding, viewing, searching, updating, and deleting products.

Built using Python's core programming concepts, the system focuses on clean code, modular design, and practical implementation of CRUD operations. Each product is managed with details such as its name, category, brand, buying price, selling price, and available quantity, making the application a realistic representation of a basic inventory management solution.

## ✨ Features

* Add new products to the inventory
* View all available products
* Search products by ID or name
* Update existing product information
* Delete products from the inventory
* Manage product stock quantities
* Store product category and brand information
* Track buying and selling prices
* Menu-driven command-line interface

## 🛠️ Technologies Used

* Python 3
* Dictionaries & Nested Dictionaries
* Functions
* Loops
* Conditional Statements
* Modular Programming

This project was created to practice real-world problem solving with Python while building a structured and maintainable command-line application.
