# 📦 Inventory Management System

A simple and efficient **Inventory Management System** developed in **Python**. This project is designed to help users manage inventory through a command-line interface. It allows users to add, update, delete, search, and purchase products while maintaining accurate stock records.

The project follows a modular programming approach, making the code easy to understand, maintain, and extend.

---

## ✨ Features

- 📊 Dashboard
- 🔐 Admin Control Panel
- ➕ Add New Products
- ✏️ Update Existing Products
- ❌ Delete Products
- 🔍 Search Products
- 🛒 Purchase Products
- 📦 View Available Inventory
- 📌 Manage Product Quantity
- 🏷️ Store Product Category
- 🏢 Store Brand Information
- 💰 Manage Buying & Selling Prices
- 📋 Menu-Driven Interface
- ⚡ Fast and Simple CLI Application

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system

### Installation

Clone the repository:

```bash
git clone https://github.com/Geld-zuerst/Inventory-Management-System.git
```

Go to the project directory:

```bash
cd Inventory-Management-System
```

Run the application:

```bash
python main.py
```

---

## 📖 How It Works

The application provides a menu-driven interface where users can:

- View all available products.
- Add new inventory items.
- Update product details.
- Delete products from inventory.
- Search products by ID or name.
- Purchase products and update stock automatically.
- Access the admin panel for inventory management.
